## 開発状況

最初の段階（M1）として、一般的な動画編集ソフトに必要な機能と、ゆっくり解説動画を最初から最後まで作るための機能を作りました。
描画は CPU（Skia）で行います。GPU での描画（Vulkan）は次の段階（M2）で入れます。

| 項目 | 状況 |
| --- | --- |
| Windows | 画面（Avalonia）を含めて使えます |
| Linux・macOS | エンジンとコマンドライン（`nmm`）での書き出しまでを対象にしています。CI（Ubuntu・macOS arm64）で、ビルドと、書き出しを含むテストが通ります。FFmpeg はどの OS でも `tools/build-native` がソースからビルドします。CI 以外の実機では、まだ確かめていません |
| 編集 | タイムライン（レイヤー・移動・トリム・分割・リップル・ロール・コピーと貼り付け・グループ化・元に戻す）、キーフレーム、合成モード、速度変更と逆再生 |
| 映像 | 映像エフェクト 15 種類、トランジション 7 種類、テキスト（縁取り・影・背景・縦書き・一文字ずつの表示・プリセット）、図形 |
| 音声 | ミキサー（音量・パン・フェード・キーフレーム）、音の高さを保った速度変更、ラウドネスの正規化、ダッキング、レベルメーター、録音 |
| セリフ | キャラクター、セリフ入力欄、台本の一括貼り付け、ColorfulTalk（旧版。同梱）と SAPI（Windows）、セリフごとの収録、立ち絵（口パク・目パチ）、字幕（SRT） |
| 書き出し | MP4（H.264・HEVC、ハードウェアエンコード）、プリセット、範囲、WAV、静止画。x264・x265 を使いたいときは、自分で入手した ffmpeg を設定の「全般」（コマンドラインは `--ffmpeg`）で指定できます |

まだ確かめていないこと：

- 本物のマイクでの録音は確かめていません（仮の入力デバイスでテストしています）。
- 立ち絵は、YMM4 の「動く立ち絵」と同じフォルダ構成を想定していますが、実際の素材では確かめていません。
- Linux の FFmpeg には VA-API を入れていません（libva がない環境でも FFmpeg を読み込めるようにするため）。Linux のハードウェアエンコードは NVENC だけで、GPU のある実機では確かめていません（使えないときは OpenH264・kvazaar で書き出します）。

性能の記録は [docs/performance.md](docs/performance.md) にあります。

## ビルドと実行

必要なもの：

- [.NET 10 SDK](https://dotnet.microsoft.com/)（`global.json` の版）
- PowerShell 7（Windows）または bash（Linux・macOS）
- CMake と C コンパイラ（`nmm_audio` のビルドに使います。Windows は Visual Studio の C++ ビルドツール）
- FFmpeg のビルドに使うもの（FFmpeg は GPL の部品を含まない構成で、ソースからビルドします）
  - Windows：[MSYS2](https://www.msys2.org/)（`C:\msys64`。ほかの場所なら環境変数 `MSYS2_ROOT` で指定）。MSYS2 のシェルで `pacman -S --needed make diffutils mingw-w64-ucrt-x86_64-{gcc,nasm,pkgconf,cmake,ninja,jq}` を実行して、必要なものを入れます
  - Linux：make・pkg-config・nasm・jq・zlib の開発用ファイル（Ubuntu なら `sudo apt install build-essential pkg-config nasm jq zlib1g-dev`）
  - macOS：Xcode のコマンドラインツールと pkgconf・jq（Homebrew）

```bash
# フォントと、FFmpeg（LGPL 版）とその部品・ColorfulTalk のソースの取得（版とハッシュは tools/native-deps.json で固定）と、nmm_audio・ColorfulTalk・FFmpeg のビルド
pwsh tools/fetch-native.ps1      # Linux・macOS は ./tools/fetch-native.sh
pwsh tools/build-native.ps1      # Linux・macOS は ./tools/build-native.sh

dotnet build NakkuntMovieMaker.slnx
dotnet test --solution NakkuntMovieMaker.slnx
```

アプリ（Windows）：

```bash
dotnet run --project src/NakkuntMovieMaker.App
```

コマンドライン（`nmm`）：

```bash
# 書き出し（拡張子が .wav なら音声だけ）
dotnet run --project src/NakkuntMovieMaker.Cli -- export samples/general/general.nmmproj -o general.mp4 --preset youtube-1080p
# 1 フレームを画像に
dotnet run --project src/NakkuntMovieMaker.Cli -- render-frame samples/yukkuri/yukkuri.nmmproj -f 1.5s -o frame.png
# 性能の計測
dotnet run --project src/NakkuntMovieMaker.Cli -c Release -- bench --project samples/general/general.nmmproj
```

`samples/` に、一般的な動画編集とゆっくり解説のサンプルプロジェクトがあります（[samples/README.md](samples/README.md)）。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| 対応 OS | Windows / Linux / macOS（Apple Silicon のみ。Intel Mac は対象外） |
| フレームワーク | .NET 10.0 |
| GPU（Windows・Linux） | Vulkan 1.2 以上に対応した GPU（NVIDIA GeForce GTX 900 以降・AMD Radeon RX 400 以降・Intel 第 6 世代 Core の内蔵 GPU 以降・Intel Arc） |
| GPU（macOS） | Apple Silicon（M1 以降・Metal 3） |
| VRAM | 内蔵 GPU（メインメモリと共有）でも動作。専用の VRAM を持つ GPU では 4GB 以上を推奨 |

基本的には LTS 版の .NET を使用しますが、将来的に LTS 版以外の .NET を使用する可能性があります。

上の表より古い GPU（GeForce GTX 700 以前・Radeon HD シリーズなど）や GPU がない環境では、CPU だけで処理します。

AI の機能は、NVIDIA GPU（CUDA）、Intel GPU（OpenVINO。内蔵 GPU・Arc）、Apple Silicon（Core ML）では GPU で処理し、それ以外の環境では CPU で処理します（処理に時間がかかります）。

### 基準となる環境

このソフトは、開発者の PC で実用的に快適に動くことを前提に開発します。

ただし、AI の機能や GPU が主力となる機能（3D・コンポジット・カラーグレーディング・重い映像エフェクト・高解像度の編集など）は、開発者の PC のスペックにはこだわらず、できる限り実用的に快適に使えることを目標にします。

開発者が使用している PC のスペックは次のとおりです。

| CPU | Intel Core i5-1145G7（4 コア 8 スレッド、2.6GHz・最大 4.4GHz） |
| GPU | Intel Iris Xe Graphics（CPU 内蔵） |
| メモリ | 16GB（LPDDR4X-4266） |
| ストレージ | NVMe SSD 256GB |
| ディスプレイ | 12.1 型、1920×1200、60Hz |
| OS | Windows 11 Pro 26H2（64 ビット） |

## 主な機能

- 動画・音声処理の方式を 2 種類用意
  - GPU を使う処理（対応 GPU は「[動作環境](#動作環境)」を参照）
  - CPU だけで行う処理（対応していない GPU や GPU がない環境でも動作）
- プラグインによる機能の拡張
  - 音声合成：新しい音声合成ソフト・サービスへの対応
  - 映像エフェクト
  - 音声エフェクト
  - トランジション
  - 図形
  - ファイルの読み込み：動画・画像・音声ファイルの対応形式
  - 動画の出力：出力形式・エンコーダー
  - ツール：編集を補助するツールやウィンドウ
- 他ソフトのプラグインとの互換性（可能な限り対応）
  - [ゆっくりMovieMaker4（YMM4）](https://manjubox.net/ymm4/)
  - [AviUtl](https://spring-fragrance.mints.ne.jp/aviutl/)
  - [AviUtl2（AviUtl ExEdit2）](https://spring-fragrance.mints.ne.jp/aviutl/)
  - VST3 プラグイン（音声エフェクト）
  - OpenFX プラグイン（映像エフェクト・トランジション・図形）
  - タイトル・モーショングラフィックスのテンプレート

## 機能一覧

似た機能は 1 つにまとめ、種類や方式を選べるようにしています。

### 編集

- タイムライン
  - レイヤー数の上限なし
  - レイヤーごとの設定（表示切り替え・ロック・名前・背景色・高さ・座標や音量の一括調整）
  - 一覧表示（アイテム・マーカー・シーン）と選択
  - タイムラインの複製表示、レイヤーの固定表示
  - グループ制御とエフェクトの適用順を選択可能
  - シーン（タイムラインの入れ子、シーンごとの解像度・フレームレート、シーンの保存・複製）
  - マーカー、BPM グリッド（複数の BPM・拍子・開始位置）、スナップ
  - 縦型タイムライン（縦長動画の編集）
  - ソーステープ（すべての素材を 1 本につないで確認）、全体と拡大の 2 段タイムライン
- 編集操作
  - ドラッグ＆ドロップでの配置、挿入・上書き・置き換えなどのスマート編集
  - 分割・カット、削除して左詰め（全レイヤーまとめても可）、範囲での切り出し、空白の挿入
  - 複数選択（矩形・範囲・レイヤー単位）、整列、複製、長さの一括変更、指定時間への移動
  - 複数アイテムの設定の同時編集、キー操作での移動・回転・拡大
  - トリム（リップル・ロール・スリップ・スライド）、操作位置に応じた自動トリム
  - 速度変更（倍速・逆再生、スピードランプ、フレーム補間による滑らかなスロー）
- マルチカメラ編集（音声での自動同期、複数カメラの同時表示、ライブ収録中の編集・リプレイ）
- キーフレーム編集（エフェクトごとに中間点を設定可能、中間点の分割・均等配置、キーフレームエディター、アニメーションカーブ）
- 移動方法（直線・曲線・加減速・瞬間移動・ランダム・反復・回転・補間移動・移動量の指定など）
- 参照式（他の項目・他のレイヤーの値の参照、計算式の入力）
- エイリアス（アイテム・エフェクト・数値の設定をファイルに保存して再利用）、初期値の設定
- 字幕・クローズドキャプションの作成と編集
- 操作履歴ツリー（任意の時点に戻す・やり直す）
- エフェクトと文字装飾のプリセット・テンプレート（まとめて保存・呼び出し・共有）
- テキストを文字ごとのアイテムに分割
- 無音カット（ジェットカット）
- マウス操作での動きの記録
- 座標を解像度に対する比率で指定
- 制御文字（AviUtl 互換：色・サイズ・フォント・装飾・表示速度・ウェイト・座標・字間・行間・変形・絵文字・ルビ・コメント・スクリプトの埋め込み）

- 影：シャドー（ドロップシャドウ）、点光源からの影、アンビエントオクルージョン
- クリッピング：上のアイテムでクリッピング、複数のアイテムでのクリッピング、マスク、斜めクリッピング、ワイプ、比率指定、扇形（AviUtl の扇クリッピング(R) 互換）、分断と間詰め、波形、領域内での拡大縮小と移動、透明な余白の除去、図形切り抜きへのエフェクト適用
- 歪み・変形：振動、ミラー、ラスター、極座標変換、ディスプレイスメントマップ、ローテーション、反転、領域拡張、リサイズ、メッシュ変形、揺らぎ、波打ち（拡張）、乱流による歪み、ベクトル場による変形、手描き風の揺れ、パペットワープ、重力レンズ

- レトロ・グリッチ：ノイズ、モザイク（タイル風）、VHS 風、ブラウン管風、VHS 風の輪郭、グリッチノイズ、データモッシュ、コマ落ち、ディザリング、ポスタリゼーション
- アート調・質感：漫画のスクリーントーン、浮世絵、クロスハッチング、切り絵、墨のにじみ、ローポリ、装飾モザイク、万華鏡、ホログラム箔、陶器・鉱物などの質感、結晶の成長、ぷっくりした立体、Blob の装飾

- 複製・残像（複製する方向・間隔・位置・不透明度などを指定）
- アイテムの上への合成：画像・動画・図形・テキストの貼り付け、ドロステ効果
- 分解：オブジェクト分割、粒子化、砕け散る、パーツ分解
- 画面分割（グループ制御中のアイテムでの画面分割の拡張）
- 描画の調整：描画位置の拡大縮小、回転に合わせた拡大、拡大率・不透明度・反転の適用順の変更、描画設定、画面に収まる拡大縮小、疑似的な不透明度、薄い部分の塗りつぶし、再生時・停止時・出力時で別の不透明度、9 スライス、操作画面の枠やハンドルの焼き込み
- 動き：画像ループ、射出、画面端での反射、画面の端から端への移動、繰り返しスクロール、1 秒あたりの回転数の指定、3D の画像ループ、円運動、物理演算（ジョイント・風や水の領域・トリガー・液体）

- スクリプトによる制御（Lua。アニメーション効果・カスタムオブジェクト・カメラ効果・シーンチェンジ・移動方法を作成可能。AviUtl のスクリプト互換と合わせて設計）
- 条件・リズムによる制御：条件を満たしたときにエフェクトを適用、BPM に合わせた制御、エフェクトのランダムな切り替え
- 線：アイテム同士を線でつなぐ、ライン行進
- アニメーション効果：震える、点滅、弾む、拡大縮小、回転など
- 登場退場：フェード、拡大縮小、回転、ランダムな方向から、リリックモーション、汎用的な登場退場
- テキスト：一文字ずつの表示、文字ごとの位置調整（カーニング）、フォントのシャッフル、文字のシャッフル、切り抜き文字風（脅迫状風）、長文のスクロール
