NakkuntMovieMaker 0.0.2 β です。0.0.1 の機能（M1）に、GPU での描画・色の管理・プロキシ編集（M2）を加えました。

## 0.0.1.1 からの変更

- **GPU で描くようにしました（Vulkan）。** 合成・エフェクト 15 種類・トランジション 7 種類・文字と図形を GPU で描きます。使える GPU がないとき・正しく描けないときは、これまでどおり CPU で描きます。
  - 設定の「描画」で、描画の方式（自動・GPU・CPU）・使う GPU・GPU のメモリの上限を選べます。状態バーに、今の描画の方式を表示します。
  - 書き出しでは、GPU がエンコーダー向けの形式（NV12）を作って渡すので、速くなりました（基準の PC で、10 分の動画の書き出しが実時間の約 3.9 倍。0.0.1 は約 2 倍）。
  - Windows では、HEVC などの動画を GPU でデコードし、メインメモリに写さずに描きます。
- **色の管理（OpenColorIO）を入れました。**
  - プロジェクトの設定：合成の色空間（sRGB・リニア）、OpenColorIO の構成、書き出しの色空間
  - 設定の「描画」：プレビューを表示するモニターの色空間
  - 素材の一覧（右クリック）：素材ごとの入力の色空間。HDR（PQ・HLG）の動画は、SDR にトーンマップして使います
- **プロキシ編集を入れました。** 大きな動画の代わりに、編集用の軽い動画（プロキシ）をプレビューだけで使います。書き出しでは元の動画を使います。
  - プロジェクトの設定で使う範囲（使わない・1080p より大きい動画だけ・すべての動画）を、素材の一覧の右クリックで作る・削除するを、「表示」のメニューでプレビューでの切り替えを行います。
  - コマンドラインの `nmm proxy` でも作れます。

> [!WARNING]
> β 版です。保存の形式や操作は、これから変わることがあります。大事なプロジェクトは、こまめにバックアップしてください。
> 0.0.1 のプロジェクトは 0.0.2 で開けますが、0.0.2 で保存したプロジェクトは 0.0.1 では開けません（プロジェクトの形式が 2 になりました）。

## 動作環境

- GPU で描くには、Vulkan 1.2 以上に対応した GPU とドライバーが要ります（NVIDIA GeForce GTX 900 以降・AMD Radeon RX 400 以降・Intel 第 6 世代 Core の内蔵 GPU 以降など）。対応していなければ CPU で描きます。
- 基準の PC（Core i5-1145G7・Iris Xe）で、フル解像度・8 レイヤー＋1080p60 の動画＋3 レイヤーにエフェクトの場面を、60fps で再生できます（飛ばしたフレーム 0.2%）。

## わかっている制限

- GPU での描画は、Intel Iris Xe（Windows）と、CI の Linux の lavapipe（CPU で動く Vulkan）・macOS の MoltenVK（仮想の GPU）で確かめています。NVIDIA・AMD の GPU では、まだ確かめていません。
- 動画を Vulkan Video でデコードする機能は、FFmpeg とドライバーの不具合で落ちることがあるため、試験的な機能として既定では使いません（設定の「描画」で使えます）。
- 立ち絵は、CPU で描いてから GPU に送ります。
- 本物のマイクでの録音、実際の立ち絵の素材での表示は、まだ十分に確かめていません。
